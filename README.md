## About Me

I am a developer passionate about building modern applications, scalable backend systems, and practical software products.

My focus is on writing maintainable code, designing useful developer tools, and turning ideas into real-world applications.

- Full-stack web development with modern JavaScript technologies.
- Backend architecture, APIs, authentication, and database systems.
- Developer tools, reusable frameworks, and SaaS products.
- Exploring AI-powered applications and software automation.

**My philosophy:** Build useful software. Keep it simple. Make it scalable.
